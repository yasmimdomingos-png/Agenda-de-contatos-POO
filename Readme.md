📱 Agenda de Contatos

    Projeto desenvolvido para a disciplina de Programação Orientada a Objetos (POO), com o objetivo de aplicar, na prática, os principais conceitos da programação orientada a objetos por meio do desenvolvimento de uma agenda de contatos.

📖 Sobre o projeto

    A Agenda de Contatos é uma aplicação desenvolvida para permitir o cadastro e o gerenciamento de informações de contatos.
    O projeto está sendo construído de forma gradual, acompanhando o aprendizado dos conceitos de Programação Orientada a Objetos. Ao longo do desenvolvimento, novas funcionalidades serão adicionadas à aplicação.

🎯 Objetivos

    - Praticar os conceitos fundamentais de Programação Orientada a Objetos;
    - Desenvolver uma aplicação utilizando classes e objetos;
    - Aprimorar a organização e estruturação do código;
    - Implementar funcionalidades relacionadas ao gerenciamento de contatos;
    - Aplicar os conhecimentos adquiridos durante a disciplina.

🛠️ Tecnologias utilizadas

    - Java
    - Programação Orientada a Objetos
    - Git e GitHub

📂 Estrutura do projeto

    A estrutura do projeto será organizada conforme o desenvolvimento da aplicação e a implementação de novas classes e funcionalidades.

👩‍💻 Desenvolvimento

    Projeto desenvolvido como atividade acadêmica da disciplina de Programação Orientada a Objetos.
